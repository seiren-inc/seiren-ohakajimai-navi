# 重複コンテンツ回避ルール（自治体ページ中心）

計画§4「タイトル・H1・導入FAQの重複を避ける」を運用で再現するための最低限のルールです。

## スコープ

- **市区町村ページ**（`/kaissou/{都道府県}/{市区町村}`）同士
- **都道府県ハブ**と**市区町村**（意図が異なるためコピペ禁止ではなく「差別化要素」を必須化）

## タイトル（`generateMetadata`）

- 形式: `{市区町村名}の改葬許可申請書ダウンロード・手続きガイド｜お墓じまいナビ` のように **自治体名を先頭付近に必ず含める**
- 隣接自治体と**同じ語順のまま地名だけ差し替え**は不可: 可能なら「ダウンロード」「手続き」「窓口」のどれか一方をページの主眼に合わせて語を置き換える（データ品質に応じて編集）

## H1

- 現行: `{municipality.name}の改葬手続き`
- 都道府県ページの H1 と同一パターンにならないよう、都道府県側は「{都道府県名}の改葬手続き・許可申請」など **階層が分かる語**を使う

## 導入文（リード）

- **1文目**に `都道府県名＋市区町村名` を含める
- **2文目以降**で「申請書」「公式ページ」「PDF」のいずれが主かを、その自治体の `linkType` / `pdfUrl` の有無に合わせて変える（同一テンプレのまま全自治体で同じ2文にしない）

## FAQ（JSON-LD 兼用）

- 質問文に必ず **市区町村名** を入れる（汎用FAQの貼り付け禁止）
- 回答の「費用」パートは数値レンジを共通化しすぎないよう、必要なら「一般的な目安」と明記し地域特征（山間部等）を1語入れる

## 内部リンク

- 同一片の「関連市区町村」大量ブロックでテキスト付け替えのみのリストを増やさない（将来追加する場合は `information-architecture-four-intents.md` のクラスに沿って意図を分ける）

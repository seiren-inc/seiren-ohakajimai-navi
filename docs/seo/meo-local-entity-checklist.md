# MEO・ローカルエンティティチェックリスト

## Google ビジネスプロフィール（オフライン运用込み）

- [ ] カテゴリ・サービス説明が Web の主要メッセージ（お墓じまい／改葬）と矛盾しない。
- [ ] サービスエリアが実サービスと一致する。
- [ ] QA・レビュー方針が文書化され、定期的に回答・運用されている。

## NAP 一貫性

- [ ] Web上の運営者表記・住所・電話・営業時間がサイトの Organization / LocalBusiness（該当する場合）と一致する。
- [ ] 姉妹サイト・ディレクトリ掲載と齟齬がないか四半期で確認する。

## サイト側

- [ ] ローカル意図のページは会社情報・対応エリア・市区町村ハブとの**往復リンク**で補強する。
- [ ] `@/lib/seo` および各 LP の JSON-LD に **二重矛盾** がないことを技術チェックリストで確認。

## KPI（可能な範囲）

- GBP の検索・マップクエリ・アクション・経路を四半期で確認（ビジネス用レポート等）。

# E-E-A-T プログラム

## 方針

正確性・信頼性を最優先し、すべてのコンテンツは **検証可能性** と **責任の所在** が追える状態にする。

## Experience（経験）

- 運営の実務知見や相談例は **匿名化** したうえで、一般論との区別を明示する。

## Expertise（専門性）

- 法令・手続きは **公的・一次ソース**へのリンクで裏付ける。
- 監修がある場合は**監修者名・資格・責務範囲**を明記する（該当テンプレート）。

## Authoritativeness（権威）

- 行政書士ハブとの関係、許認可、所在地・連絡先など **外部確認可能な事実**を揃える。

## Trustworthiness（信頼）

- プライバシーポリシー／特商法／問い合わせ・誤情報訂正窓口を明確にする。
- **最終更新日**の運用ルールを決める（自治体ページの `updatedAt` 表示と連動）。
- **`ContentProvenance`**（公式URL・更新・出典）を重要ページで利用する。

## コンポーネント共通化

- 「監修」「更新日」「出典」パターンを同一UIトーンで適用する（フラット単色での安易な差し込みは避け、プロジェクトCSS変数準拠）。

## 適用優先順位

1. コア5LP  
2. 市区町村テンプレ  
3. コラム監修ページ  

## 監査方法

フェーズごとに、上記チェック項目をスクショまたはURLリストで証跡として残す。

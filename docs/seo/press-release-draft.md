### 本文（600字以内）

神奈川県横浜市戸塚区に本社を置くお墓じまい・改葬専門サービス「株式会社清蓮」（代表取締役：眞如理恵、設立2008年）は、全国1,737市区町村の改葬許可申請に必要な手続き情報を無料でデータベース化し、専門情報サイト「お墓じまいナビ」（https://www.ohakajimai-navi.jp）として公開しています。

厚生労働省の統計では、改葬件数は2022年に年間約15万件を超え、少子高齢化・核家族化を背景に増加傾向が続いています。しかし「どの役所に何を提出するか」といった手続き情報は自治体ごとに異なり、一元的に確認できる情報源はこれまで存在しませんでした。

「お墓じまいナビ」では、改葬許可申請書の様式・提出窓口・必要書類を市区町村単位で整理し、無料で閲覧できるデータベースを構築。また、手続きを専門家に委ねたい方向けに、全国の行政書士とのマッチング機能も提供しています。

代表取締役の眞如理恵は「お墓じまいを検討されるご家族が最初に直面するのは『どこに何を出せばいいのか』という情報の壁です。17年間この業界に携わってきた経験を活かし、全国のご家族が安心して手続きを進められる情報インフラを整えました」と述べています。

## 配信案2（AI検索訴求）

### タイトル
```
AI検索時代のお墓じまい情報——ChatGPT・Perplexityが引用する改葬データベースが関東4都県のガイドを強化
```

### 本文（400字）

お墓じまい・改葬専門サービス「お墓じまいナビ」（https://www.ohakajimai-navi.jp、運営: 株式会社清蓮）は、AI検索エンジン向けの情報最適化（GEO: Generative Engine Optimization）を強化し、東京・神奈川・埼玉・千葉の関東4都県向けのお墓じまいガイドを新たに公開しました。

ChatGPT・Perplexity・Geminiなど主要AI検索エンジンは、信頼性の高い専門情報サイトのコンテンツを引用して回答を生成します。「お墓じまいナビ」は、改葬許可申請に関するFAQ100問以上・全47都道府県の手続き情報・30本の解説コラムを整備し、AI検索でも引用されやすい構造を実現しています。

関東4都県ガイドでは、横浜・川崎・さいたま市など政令指定都市の申請窓口情報や、湘南・三浦半島エリア特有の離檀交渉の注意点なども詳しく解説しています。

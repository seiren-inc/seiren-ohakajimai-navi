## コンテンツ構造

- [ ] **定義1文 → 結論 → 根拠（公的リンク）→ 手順 → FAQ** の流れになっているか。
- [ ] 段落が短く、見出し階層が抜け抄しやすいか（パッセージ単位の明瞭さ）。
- [ ] 「誰が・いつ・どこへ・何を」を市区町村レベルで埋められるか。
- [ ] 「一般的には」だけで終わる箇所に、脚注または公式URLがあるか。
- [ ] 重複・曖昧表現が他ページと増殖していないか（キーワード詰めではなく検証可能性で勝つ）。

## サイト側シグナル

- [ ] `public/llms.txt` にサイト案内・主要ハブ・清蓮グループ公式一覧が記載されている（canonical方針と矛盾しない）。

## メタ／構造化

- [ ] タイトル・ディスクリプション・`FAQPage` JSON-LD が実コンテンツと一致している。

# フェーズ2 成長ループ（No.1）

## 1. クラスタ拡張

- **1意図1URL** を維持し、主要4KWごとに深掘り子ページを追加するときは **親ハブからのリンク設計を先に**書く。
- 「改葬許可申請書」系は自治体別ロングテールを計画的に増やす（重複FAQ・類似見出しに注意）。

## 2. 内部リンク

- コアLP → 市区町村の **文脈リンク** に再編（機械的同型フッター大量リンクは増やさない）。
- 市区町村 → 親LP の往復パスが枯れないこと（孤立ページゼロ）。

## 3. CTR 改善（2〜4週サイクル）

- GSCで高表示・低CTRのクエリを優先して title / description を改稿。
- 改稿履歴と期間はスプレッドシートで保持。

## 4. 月次監査

同一ダッシュボードで以下を確認:

- 技術SEO・構造化データ
- インデックス状態（カバレッジの異常）
- CWV 代表ページ
- 内部リンク構成の抜け
- `public/llms.txt` 等エージェント向けドキュメントの鮮度
- GBP 指標（取得できる範囲で）

四半期: 競合・AI検索環境での引用の質をサンプル定性レビュー。

## 停滞時の打ち手順序

競合差分 → 検索意図の再定義 → テンプレ更新 → E-E-A-T 強化。

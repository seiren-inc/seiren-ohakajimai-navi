「先祖代々の菩提寺が廃寺になったと連絡が来た」「住職が亡くなって寺が続かなくなり、お墓をどうすればいいかわからない」

近年、檀家数の減少や住職の高齢化により、**寺院が廃寺・閉院になるケース**が全国で増えています。特に地方の農村部では後継者不在による廃寺が相次いでいます。

このページでは、**菩提寺が廃寺・閉院になった場合のお墓の法的扱い・具体的な対処手順・費用相場**を解説します。

なお、「寺院がお墓じまいを拒否している」というケースとは対処法が異なります。拒否トラブルについては[お墓じまいを菩提寺に断られた時の対処法](/blog/hakajimai-kyozetsu-taisho)をご参照ください。

## 廃寺になるとお墓はどうなるか

廃寺とは、寺院が宗教法人としての活動を停止し、解散または休眠状態になることです。廃寺の形態はさまざまです。

- **住職の死亡・高齢化** により後継者がなく、宗教活動を停止するケース
- **本山（宗派）による合併・統廃合** によって寺籍が別の寺に移管されるケース
- **宗教法人の解散認定** を受けて行政手続きが完了するケース
- **事実上の休眠状態** で管理者が不在になるケース

廃寺になっても、**墓地として許可された土地は残り続けます**。お骨・墓石はそのまま残るため、改葬するまで管理義務は続きます。しかし管理する主体がいなくなると、草刈りや清掃が行われなくなり、やがて荒廃します。

<InfoBox title="廃寺と「無縁墓」は別の問題です">
  廃寺になっても、そこにあるお墓がすぐに「無縁墓」として処理されるわけではありません。ただし、管理主体が消滅し管理費の徴収が止まると、将来的に無縁化するリスクは高まります。早めに改葬を検討することが遺族への最善の配慮になります。
</InfoBox>

## 廃寺の場合の改葬許可申請：埋葬証明書の取得が鍵

改葬（お墓の引越し）には必ず市区町村への**改葬許可申請**が必要です。申請には通常「埋葬証明書（埋蔵証明書）」が必要ですが、廃寺の場合は発行してくれる主体が不明になることがあります。

### 状況別の対処窓口

| 廃寺の状況 | 埋葬証明書の依頼先 |
|------------|------------------|
| 住職は健在だが寺を閉じた | 元住職本人に依頼 |
| 住職が死亡・連絡不可 | 宗派の本山・管区内の上位寺院 |
| 別の寺に合併・統合された | 合併先の寺院 |
| 宗教法人が解散済み | 清算人・宗務庁・都道府県担当課に照会 |
| 墓地管理が自治体に移管された | 管轄市区町村の担当課 |
| 発行先が完全に不明 | 行政書士・弁護士に相談 |

<InfoBox title="埋葬証明書が取得困難な場合の代替対応">
  改葬許可申請において、埋葬証明書の取得が「著しく困難」と認められる場合は、市区町村の担当窓口の判断で他の書類（戸籍謄本・納骨時の写真・埋葬台帳の写しなど）で代替できることがあります。必ず申請前に担当窓口へ相談してください。
</InfoBox>

## 廃寺からの改葬：具体的な手順

廃寺になった寺院のお墓を改葬する流れは以下の通りです。通常の改葬よりも確認事項が多くなります。改葬許可の基本的な取り方については[改葬許可の取得方法](/blog/how-to-get-kaisoukyoka)もあわせてご参照ください。

### ステップ①：廃寺の状況を確認する

まず、菩提寺がどういう状態になっているかを把握します。

- 住職・寺族への連絡（旧住所・電話番号で試みる）
- 宗派本山（総本山・管区本山など）への問い合わせ
- 管轄市区町村への相談（墓地許可の管理状況の確認）

### ステップ②：新しい納骨先を決める

改葬許可申請には、移転先の「受入証明書」が必要です。先に新しい供養先（永代供養墓・納骨堂・樹木葬など）を決め、受入証明書を入手してください。

### ステップ③：埋葬証明書を取得する

上記の状況別窓口を参照し、埋葬証明書を取得します。取得が困難な場合は、**行政書士への相談を強くお勧めします**。

### ステップ④：改葬許可申請を市区町村に提出する

現在のお墓がある市区町村の担当窓口（環境課・生活衛生課等）に書類を提出します。基本的な提出書類は以下の通りです。

1. 改葬許可申請書
2. 埋葬証明書（または代替書類）
3. 受入証明書
4. 申請者の身分証明書

### ステップ⑤：墓石撤去・閉眼供養・遺骨の移送

改葬許可証を受け取ったら、石材店に墓石撤去を依頼します。撤去前に閉眼供養（お性根抜き）を行うのが一般的です。ただし住職が不在の場合は、近隣の同宗派の寺院や、移転先の寺院・霊園に依頼することもできます。

遺骨を新しい納骨先に納め、手続き完了です。

## 廃寺からの改葬にかかる費用相場

廃寺の場合、状況確認や書類取得に追加の時間・費用がかかることがあります。

| 費用項目 | 相場 |
|---------|------|
| 墓石撤去工事費 | 10万〜30万円 |
| 閉眼供養のお布施 | 0〜5万円（寺が不在の場合は不要なことも） |
| 行政書士費用（書類代行・照会込み） | 5万〜15万円 |
| 本山・宗務庁への問い合わせ費用 | 数千円〜数万円（交通費含む場合） |
| 遺骨の粉骨・洗骨（必要な場合） | 1万〜3万円/柱 |
| 新しい納骨先（永代供養など） | 10万〜80万円 |

**総合計の目安：30万〜120万円**

廃寺からの改葬は状況が複雑なほど、行政書士への依頼が費用・時間の両面で合理的です。

## 行政書士への相談を検討すべきケース

廃寺に絡むお墓の問題は、通常の改葬よりも専門的な知識が必要です。以下のケースでは早めに行政書士へ相談することをお勧めします。

- 住職・寺族と連絡が取れない
- 本山の名前・連絡先が不明
- 宗教法人が解散しており書類の取得方法がわからない
- 複数の遺骨が埋葬されており、一度に対応したい
- 親族間で改葬先の意見が分かれている
- 墓石撤去業者の選定も含めてまとめて任せたい

行政書士は、書類の代行だけでなく、本山・自治体への照会、石材店との調整まで対応できる専門家です。

## まとめ

- 廃寺になっても改葬許可申請は必要。管理者が不在でも遺骨を無断で持ち出してはいけない
- 埋葬証明書の発行先は廃寺の状況によって異なる（元住職・本山・自治体等）
- 発行主体が不明な場合でも、市区町村窓口への相談で代替書類対応ができることがある
- 廃寺からの改葬費用は30万〜120万円程度が目安
- 状況が複雑な場合は行政書士への早めの相談が時間・費用の節約になる

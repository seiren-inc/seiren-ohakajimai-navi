海外に移住している、または長期間海外に滞在している場合でも、日本に残したお墓を整理したいと考える方は少なくありません。しかし「帰国できない」「平日に日本の役所へ行けない」「現地で立ち会えない」といった不安から、なかなか動き出せないケースも多いようです。

この記事では、**海外在住者が日本の墓じまい・改葬を進める際の具体的な手順と、帰国なしに進めるための方法**を解説します。

## 海外在住者が直面する墓じまいの主な課題

通常の[墓じまいの流れ](/blog/hakajimai-nagare)でも手続きはいくつかありますが、海外在住者の場合は次のような追加の課題があります。

**① 役所への来庁が難しい**

改葬許可申請は、現在のお墓がある市区町村の窓口に書類を提出する必要があります。海外在住の場合は郵送や代理人での申請が必要です。

**② 閉眼法要への参加が困難**

お墓の撤去前に行う[閉眼法要（魂抜き）](/blog/heigan-houyo)には立ち会いたいと考える方も多いですが、海外にいる場合は物理的に難しいことがあります。

**③ 石材店・菩提寺との折衝**

墓石撤去業者の選定や離檀交渉は、直接会って話す方がスムーズです。電話・メール・ビデオ通話での対応になる場合があります。

**④ 費用の支払い**

国際送金は手数料が高くなることがあります。日本に家族や親族がいる場合は立替払いを依頼する方法が現実的です。

## 帰国なしで進める改葬手続きの全体フロー

改葬の基本的な手続きの順序は、海外在住者でも国内在住者でも変わりません。海外在住者の場合は「代理人（行政書士）」を活用することで、多くのステップを日本に帰国せずに完了できます。

```
1. 改葬先（新しい納骨先）を決める
   ↓（資料請求・問い合わせはオンライン・郵便で対応可）

2. 改葬先から「受入証明書」を取り寄せる

3. 行政書士（代理人）に委任状を送付する

4. 行政書士が菩提寺・管理者から「埋葬証明書」を取得

5. 行政書士が市区町村に「改葬許可申請書」を提出

6. 「改葬許可証」が発行される

7. 石材店が閉眼法要後に遺骨を取り出し、新しい納骨先へ納める
```

1〜6のステップは代理人（行政書士）に委任でき、帰国なしに完了できる可能性があります。工程7（遺骨の取り出し・搬送）は石材店や専門業者が対応するため、申請者本人が現地に行く必要はありません。

| 手続きステップ | 帰国の要否 | 代替手段 |
|-------------|----------|---------|
| 改葬許可申請書の提出 | 原則不要 | 行政書士が代理提出 |
| 埋葬証明書の取得 | 不要 | 行政書士が取得代行 |
| 受入証明書の取得 | 不要 | 郵送・メールで受取 |
| 閉眼法要への参加 | 場合による | ビデオ通話での立会に対応する場合も |
| 墓石撤去 | 不要 | 石材店が対応 |
| 遺骨の搬送 | 不要 | 専門業者が代行 |
| 改葬先への納骨 | 場合による | 代理納骨を受け付ける施設もある |

## 委任状の作り方と在外公館（大使館・領事館）での手続き

改葬手続きを行政書士に代理してもらうには、**委任状**が必要です。委任状とは、特定の人物に代わりに手続きを行う権限を与える書面です。

<InfoBox title="委任状に記載すべき主な内容">
  委任者の氏名・住所（現在の居住国の住所）、受任者（行政書士）の氏名・住所・行政書士登録番号、委任事項（改葬許可申請に関する一切の行政手続き）、作成年月日、委任者の署名
</InfoBox>

### 在外公館でのサイン証明（署名証明）

海外から送付する委任状の真正性を高めるため、**在外公館（日本大使館・総領事館）でのサイン証明（署名証明）**を取得する方法があります。サイン証明とは、「この署名は確かに本人のものである」と在外公館が証明するサービスです。

| 在外公館で取得できるサービス例 | 内容 |
|------------------------------|------|
| 署名（サイン）証明 | 委任状等の署名が本人のものであることを証明 |
| 在留証明 | 現在の居住国での住所・居住事実を証明 |
| 戸籍謄本の申請代行 | 日本の市区町村への戸籍謄本請求を大使館経由で実施 |

在外公館のサービス内容・必要書類・費用・予約方法は国や地域によって異なります。必ず最寄りの大使館・総領事館のウェブサイトまたは電話で確認してください。

なお、委任状の公証（ノータリゼーション）の要否は申請する市区町村の窓口要件によって異なります。多くの場合は公証なしの委任状でも受理されますが、スムーズに手続きを進めるため、依頼先の行政書士に事前確認することをおすすめします。

## 行政書士に依頼するメリットと費用相場

海外在住者が墓じまいを進める場合、**行政書士への依頼が特に有効**です。行政書士は改葬許可申請に関する書類の作成・提出・受取代行ができる専門家であり、委任を受けた代理人として窓口に出向くことができます。

詳しい費用の目安は[行政書士への依頼費用](/blog/gyoseishoshi-itaku-hiyo-soba)の記事もご参照ください。

| 依頼内容 | 費用目安 |
|---------|---------|
| 改葬許可申請書の作成・提出代行 | 3万〜8万円 |
| 埋葬証明書・受入証明書の取得代行 | 込みの場合が多い |
| 石材店・粉骨業者の手配サポート | 実費別途 |
| 閉眼法要の手配サポート | 実費別途 |

行政書士によっては海外在住者向けのメール・ビデオ通話での対応や、書類の国際郵便転送に慣れた事務所もあります。依頼前に「海外在住者の対応実績があるか」を確認することをおすすめします。

## 海外在住者が気をつけるべきポイント

### 書類の有効期限に注意する

埋葬証明書など改葬申請に必要な書類には、市区町村によって「発行から○ヶ月以内」という期限が設けられている場合があります。書類の発行タイミングと申請時期が離れすぎないよう、手続き開始前に確認しましょう。

### 一時帰国が必要になるケース

帰国不要で進めることが目標であっても、以下のような場合は一時帰国が必要になることがあります。

- 菩提寺との離檀交渉が長引き、直接話し合いが必要になった場合
- 閉眼法要への立会いを菩提寺が条件としている場合
- 改葬先の施設が、申請者本人の来訪を契約条件としている場合

帰国が難しい時期がある場合は、手続きを始める前に行政書士と「一時帰国が必要になる可能性と代替手段」について確認しておきましょう。

### 改葬先は早めに決める

改葬先（新しい納骨先）が決まっていないと手続きが開始できません。資料請求や見学はオンラインや郵便で対応している施設も多いため、帰国前に候補先を絞り込んでおくと手続きがスムーズです。[永代供養の選び方](/blog/eitaikuyo-toha)や[納骨堂の選び方](/blog/noukotsu-dou-erabikata)も参考にしてください。

### 離檀料の交渉は慎重に

菩提寺との離檀交渉では、[離檀料](/blog/ridanryou-soba)について話し合いが必要になることがあります。離檀料に法的な支払い義務はありませんが、寺院との関係を大切にしながら進めることが重要です。海外からの交渉は誤解が生じやすいため、文書（手紙・メール）での記録を残すようにしましょう。

## まとめ

海外在住者でも、日本のお墓じまい・改葬は進めることができます。行政書士への委任と委任状の準備（必要に応じて在外公館でのサイン証明）によって、帰国なしに手続きの多くを完了できる可能性があります。

ただし、菩提寺との離檀交渉の状況や自治体窓口の要件によっては、一時帰国が必要になるケースもあります。早めに専門家に相談し、全体のスケジュールと必要な準備を確認することをおすすめします。

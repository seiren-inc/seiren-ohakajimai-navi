静岡県は富士山の麓に広がる豊かな自然と、古くから続く禅宗・曹洞宗・臨済宗などの寺院が数多く存在する地域です。政令指定都市である静岡市（葵区・駿河区・清水区）を中心に、浜松市・沼津市・富士市など人口規模の大きな都市が連なります。少子高齢化や核家族化が進む中、**静岡県でもお墓じまい・改葬の相談件数は年々増加**しています。本記事では、静岡市を中心に静岡県全域の改葬手続き・費用・窓口情報をまとめました。

## 静岡県での改葬手続きの基本フロー

改葬の基本的な手続きは全国共通です。まず大まかな流れを把握しておきましょう。

<InfoBox title="改葬の基本フロー（全国共通）">
  1. 新しい納骨先を決め「受入証明書」を取得する
  2. 現在のお墓の管理者（寺院・霊園等）から「埋葬証明書」を取得する
  3. 現在のお墓がある市区町村役場に「改葬許可申請書」を提出する
  4. 「改葬許可証」を受け取る
  5. お墓から遺骨を取り出し、新しい納骨先へ納める
</InfoBox>

申請に必要な書類は、①改葬許可申請書、②埋葬証明書（旧墓地管理者発行）、③受入証明書（新しい納骨先発行）、④申請者の身分証明書、⑤認印が基本セットです。書類の様式は各市区町村によって異なるため、事前に窓口で確認するか、ホームページからダウンロードしてください。

## 静岡市3区の申請窓口

静岡市は3つの行政区に分かれており、改葬許可申請は**現在のお墓がある区の区役所**に提出します。

| 区名 | 主な担当窓口 |
|------|-------------|
| 葵区 | 葵区役所 市民課 |
| 駿河区 | 駿河区役所 市民課 |
| 清水区 | 清水区役所 市民課 |

<InfoBox title="申請前に必ず電話確認を">
  担当課名・受付時間・郵送申請の可否は変更になる場合があります。申請前に必ず各区役所の公式ホームページまたは電話でご確認ください。なお、清水区は旧清水市と旧蒲原町・由比町が合併した広域エリアのため、飛び地の墓地がある場合は所在地番をよく確認してから窓口に問い合わせることをおすすめします。
</InfoBox>

## 静岡県特有の注意点

### ① 禅宗寺院が多く、離檀交渉が必要なケースがある

静岡県は臨済宗・曹洞宗の寺院が非常に多い地域です。歴史ある菩提寺が多く、数百年にわたって先祖代々の墓守をしてもらったご家庭では、**離檀（檀家をやめること）の際に住職との丁寧な話し合い**が必要になるケースがあります。

突然の申し出ではなく、まず寺院に「墓じまいを検討している」と相談の場を設けることが、トラブルを防ぐ最善策です。

### ② 山間部・離島での墓地アクセスと石材店の確保

伊豆半島・奥大井・天竜川上流域などの山間部では、対応できる石材店が少なく出張費が加算されるケースがあります。また伊豆大島や式根島など**伊豆諸島の一部は東京都に属する**ため、郵便物の送付先や申請先が異なります（東京都管轄）。離島や山間部のお墓の場合は、現地事情に精通した行政書士に相談することをおすすめします。

<InfoBox title="伊豆諸島（伊豆大島・式根島等）のお墓は東京都管轄">
  伊豆大島・利島・新島・式根島・神津島・三宅島・御蔵島・八丈島・青ヶ島・小笠原などは東京都に属します。これらの島にあるお墓の改葬申請は、各島の村役場（東京都管轄）への申請となります。静岡市や静岡県の窓口ではありませんのでご注意ください。
</InfoBox>

### ③ 旧市町村合併による墓地の所在地確認

静岡県は2000年代の平成の大合併によって多くの市町村が合併しました。古い書類に記載された地名と現在の行政区分が異なる場合があり、改葬申請の提出先を間違えるケースがあります。古い埋葬証明書や墓地使用規則を持っている場合は、現在の正確な住所（地番）を確認してから申請窓口を特定することが重要です。

静岡市・静岡県内でお墓じまい・改葬を行う場合の費用目安を以下の表にまとめました。

| 費用項目 | 相場 |
|---------|------|
| 墓石撤去工事費（一般的な大きさ） | 10万〜30万円 |
| 閉眼供養（魂抜き）のお布施 | 3万〜5万円 |
| 離檀料（任意・強制ではない） | 0万〜30万円 |

| 行政書士への代行費用 | 5万〜15万円 |
| 遺骨の洗骨・粉骨（1柱あたり） | 1万〜3万円 |
| 新しい納骨先（永代供養） | 10万〜50万円 |
| 新しい納骨先（樹木葬） | 5万〜30万円 |

**総合計の目安：30万〜100万円程度**

山間部や離島へのアクセスが必要な場合は石材店の出張費が加算されます。複数の石材店・行政書士から見積もりを取り、費用を比較することをおすすめします。

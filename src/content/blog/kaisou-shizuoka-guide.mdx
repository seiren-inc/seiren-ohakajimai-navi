静岡県は東海道の中心に位置し、富士山・伊豆・駿河湾に囲まれた歴史ある地域です。古くから曹洞宗・臨済宗の寺院が多く、先祖代々のお墓を守ってきた家庭も少なくありません。一方で、近年は少子高齢化と都市部への人口移動により、**静岡に残るお墓を誰も管理できなくなる**という状況が増えています。本記事では静岡市（3区）を含む静岡県内での改葬・お墓じまいの手続き・費用・注意点を詳しく解説します。

## 静岡市3区の申請窓口

静岡市は政令指定都市であり、**葵区・駿河区・清水区**の3つの行政区で構成されています。改葬許可申請は現在のお墓がある区の区役所に提出します。

| 区名 | 担当窓口の例 |
|------|------------|
| 葵区 | 葵区役所 市民課（環境衛生担当） |
| 駿河区 | 駿河区役所 市民課 |
| 清水区 | 清水区役所 市民課 |

<InfoBox title="静岡市の申請前に必ず確認を">
  担当課名・受付時間・郵送申請の可否は変更になる場合があります。申請前に必ず各区役所の公式ホームページまたは電話で確認してください。静岡市公式サイト（https://www.city.shizuoka.lg.jp）でも最新情報を確認できます。
</InfoBox>

## 改葬の基本的な流れ

改葬手続きは全国共通の墓地埋葬法に基づいており、以下の流れで進めます。

<InfoBox title="改葬の基本フロー（全国共通）">
  1. 新しい納骨先を決め「受入証明書」を取得する
  2. 現在のお墓の管理者（寺院・霊園等）から「埋葬証明書」を取得する
  3. 現在のお墓がある市区町村役場に「改葬許可申請書」を提出する
  4. 「改葬許可証」を受け取る
  5. 石材店に墓石撤去を依頼し遺骨を取り出す
  6. 新しい納骨先へ遺骨を納める
</InfoBox>

必要書類は以下の通りです。

| 書類名 | 入手先 |
|--------|--------|
| 改葬許可申請書 | 市区町村役場（無料） |
| 埋葬証明書 | 現在の墓地管理者（寺院・霊園） |
| 受入証明書 | 新しい納骨先の管理者 |
| 申請者の身分証明書 | 本人所持 |
| 印鑑（認印可） | 本人所持 |

## 静岡県特有の注意点

### ① 曹洞宗・臨済宗寺院と離檀交渉

静岡県は古くから**曹洞宗・臨済宗の寺院が多い**地域です。お寺の檀家となっている場合、改葬（離檀）の際には寺院との交渉が必要です。

離檀料（お寺を離れる際のお布施）に法的な支払い義務はありませんが、慣習として3万〜30万円程度を求められることがあります。高額の離檀料を要求された場合や、寺院側が改葬に応じてくれないと感じたときは、**行政書士に相談する**ことで円満解決につながるケースが多くあります。

### ② 伊豆・富士山麓の山間部・離島での注意

伊豆半島や富士山麓の山間部では、地域によって対応できる石材店が少ない場合があります。遠方からの出張費が加算され、墓石撤去費用が都市部より割高になることがあります。

また伊豆の離島（初島など）でのお墓じまいでは、海上輸送の問題から特別な段取りが必要です。まず現地の石材店や行政書士に相談することをおすすめします。

### ③ 関東・東海への改葬ニーズ

静岡県は東京・名古屋両都市圏への通勤圏でもあり、若い世代が関東や東海に移住したものの、**実家のお墓は静岡に残っている**というケースが非常に多くなっています。遠隔地からの手続きに対応するため、郵送での申請受付や行政書士への代行依頼を活用する方が増えています。

## 費用相場

静岡県内での改葬・お墓じまいにかかる費用の目安は以下の通りです。

| 費用項目 | 相場 |
|---------|------|
| 墓石撤去工事費 | 10万〜25万円 |
| 閉眼供養（魂抜き）のお布施 | 3万〜5万円 |
| 離檀料（任意・法的義務なし） | 0〜30万円 |
| 改葬許可申請書類取得 | 数百円〜無料 |
| 行政書士への代行費用 | 5万〜12万円 |
| 遺骨の洗骨・粉骨 | 1万〜3万円/柱 |
| 新しい納骨先（永代供養・納骨堂等） | 10万〜50万円 |

**総合計の目安：25万〜90万円**

山間部・離島では石材店の出張費が加算される場合があります。必ず複数の業者から見積もりを取ってください。

## よくある改葬先の選択肢

静岡県内でお墓じまい後の改葬先として選ばれることが多い供養方法は以下の通りです。

| 供養方法 | 費用目安 | 特徴 |
|---------|---------|------|
| 永代供養墓 | 20万〜60万円 | 寺院や霊園が永続管理。後継者不要 |
| 樹木葬 | 15万〜60万円 | 自然志向。宗教不問が多い |
| 納骨堂 | 20万〜80万円 | 屋内管理。アクセスしやすい |
| 海洋散骨 | 5万〜20万円 | 遺骨を海に撒く。墓地が不要 |
| 手元供養 | 1万〜10万円 | 遺骨の一部を手元に保管 |

駿河湾・遠州灘に面した静岡県では、**海洋散骨**を選ぶ方も増えています。新しい納骨先を選ぶ際は、将来的に誰がお参りするかを家族で話し合ってから決めることが重要です。

## まとめ

- 申請窓口は「現在のお墓がある市区町村の役所（区役所）」
- 静岡市は3区（葵・駿河・清水）に分かれており区役所ごとに申請が必要
- 浜松市は政令指定都市のため各区の区役所が窓口
- 曹洞宗・臨済宗寺院との離檀交渉は行政書士のサポートが有効
- 伊豆・山間部・離島では石材店の出張費が加算されることがある
- 遠隔地からの手続きには郵送申請・行政書士代行が便利
- 離檀料に法的支払い義務はない

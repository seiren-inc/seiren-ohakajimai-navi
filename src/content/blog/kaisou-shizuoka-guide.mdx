静岡市は葵区・駿河区・清水区の3区で構成される政令指定都市です。久能山東照宮の門前町として歴史ある寺院が多く、安倍川流域を中心に古くから続く檀家関係を持つ家庭も少なくありません。お墓じまい（改葬）の手続きは全国共通の墓地埋葬法に基づきますが、**申請窓口や担当課は区ごとに異なります**。静岡市ならではの注意点とともに、改葬の全工程を解説します。

## 静岡市での改葬手続きの基本フロー

改葬の流れは全国共通です。静岡市での手続きもこの順序で進めます。

```
1. 新しい納骨先を決める（受入証明書をもらう）
   ↓
2. 現在のお墓の管理者から「埋葬証明書」をもらう
   ↓
3. お墓がある区の区役所に「改葬許可申請書」を提出
   ↓
4. 「改葬許可証」を受け取る
   ↓
5. 遺骨を取り出し、新しい納骨先へ納める
```

<InfoBox title="静岡市での申請先：区ごとに窓口が異なります">
  静岡市は政令指定都市（3区）のため、改葬許可申請はお墓がある区の区役所に提出します。葵区・駿河区・清水区でそれぞれ担当課が設けられており、担当課名は「市民課」「生活環境課」などと区によって異なります。申請前に各区役所のホームページで最新情報を確認してください。
</InfoBox>

## 必要書類

静岡市内で改葬許可申請を行う際に一般的に必要な書類は以下の通りです。

| 書類名 | 入手先 |
|--------|--------|
| 改葬許可申請書 | 各区役所窓口またはホームページ |
| 埋葬証明書 | 現在のお墓の管理者・寺院 |
| 受入証明書 | 移転先の霊園・納骨堂等 |
| 申請者の身分証明書 | 運転免許証・マイナンバーカード等 |
| 印鑑（認印可） | 申請者が持参 |

場合によっては**戸籍謄本・委任状・墓地使用許可証のコピー**が求められることがあります。特に先祖代々のお墓で代表者が申請する場合は、委任状の準備が必要になることがあります。

<InfoBox title="複数の遺骨が納められている場合">
  1基のお墓に複数の遺骨が埋葬されている場合、遺骨ごとに改葬許可申請が必要になることがあります。申請数が多い場合は手続きが複雑になるため、行政書士への相談をおすすめします。
</InfoBox>

## 静岡市特有の注意点

### ① 寺院墓地の離檀交渉

静岡市内には久能山周辺・安倍川沿いをはじめ、歴史ある寺院が多数存在します。長年の檀家関係があるお寺からの墓じまいでは、**離檀交渉**が課題になることがあります。

離檀料に法的支払い義務はありませんが、慣習として3〜10万円程度を求めるお寺があります。高額な離檀料を求められた場合や、寺院から改葬を拒否された場合は、その場での返答を避け、行政書士にご相談ください。

### ② 静岡市の公営墓地からの改葬

静岡市が管理する公営墓地（麻機霊園・久能山霊園など）からの改葬では、民間寺院と異なり**離檀料が発生しません**。各墓地管理事務所に連絡して埋葬証明書を取得し、区役所へ改葬許可申請を進めます。ただし、墓所の**返還手続き**が別途必要になります。

### ③ 清水区・旧清水市エリアの注意点

2003年に静岡市と合併した旧清水市エリア（清水区）では、合併前から続く寺院・霊園も多く存在します。清水区内の申請は清水区役所が窓口となり、旧静岡市エリアとは別の担当窓口になります。合併前に取得した墓地使用契約書等の書類が残っているか確認しておくとスムーズです。

## 費用相場

静岡市内でお墓じまい・改葬を行う際の費用目安は以下の通りです。

| 費用項目 | 相場 |
|---------|------|
| 墓石撤去工事費 | 10万〜25万円 |
| 閉眼供養（魂抜き）のお布施 | 3万〜5万円 |
| 離檀料（任意・寺院墓地のみ） | 0〜10万円 |
| 改葬許可申請書類取得 | 数百円 |
| 行政書士への代行費用 | 5万〜12万円 |
| 遺骨の洗骨・粉骨 | 1万〜3万円/柱 |
| 新しい納骨先（永代供養・樹木葬等） | 10万〜60万円 |

**総合計の目安：30万〜90万円**

静岡市内でも、葵区・駿河区の中心部と清水区・中山間地では石材業者の費用が異なる場合があります。複数の業者に見積もりを取って比較することをおすすめします。

<InfoBox title="費用を抑えるポイント">
  墓石撤去は複数の石材業者に相見積もりを取ることで10万円以上節約できるケースがあります。また、散骨・樹木葬・手元供養など納骨先の選択によっても総費用が大きく変わります。
</InfoBox>

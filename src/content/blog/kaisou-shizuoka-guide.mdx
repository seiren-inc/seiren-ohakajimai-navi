静岡県は富士山を擁する太平洋岸の大県で、政令指定都市が静岡市・浜松市の2つあります。温暖な気候と自然環境から古くからの寺社・墓地も多く、**先祖代々のお墓が山間の寺院にある**というご家庭も少なくありません。遠方への引っ越しや後継者不在を機に改葬・お墓じまいを検討する方が増えています。手続きの流れから市区町村ごとの窓口、費用相場まで詳しく解説します。

## 静岡県での改葬手続きの基本

改葬（遺骨を別の場所へ移すこと）の手続きは、全国どの都道府県でも法律（墓地・埋葬等に関する法律）に基づいて進めます。

<InfoBox title="改葬の基本フロー（全国共通）">
  1. 新しい納骨先を決め「受入証明書」を取得
  2. 現在のお墓の管理者（寺院・霊園等）から「埋葬証明書」を取得
  3. 現在のお墓がある市区町村役場に「改葬許可申請書」を提出
  4. 「改葬許可証」を受け取る
  5. 遺骨を取り出し、閉眼供養を行ったうえで新しい納骨先へ納める
</InfoBox>

必要書類は自治体によって若干異なりますが、基本的には改葬許可申請書・埋葬証明書・受入証明書・申請者の身分証明書・印鑑です。事前に役所のホームページや電話で確認しておくとスムーズです。

静岡市は葵区・駿河区・清水区の3つの行政区で構成されています。改葬許可申請は**現在のお墓がある区の区役所**に提出します。

| 区名 | 担当窓口の例 |
|------|------------|
| 葵区 | 葵区役所 市民課 |
| 駿河区 | 駿河区役所 市民課 |
| 清水区 | 清水区役所 市民課 |

<InfoBox title="申請前に窓口へ確認を">
  担当課名・受付時間・郵送申請の可否・必要書類は変更になる場合があります。申請前に必ず各区役所の公式ホームページまたは電話で最新情報を確認してください。
</InfoBox>

## 静岡県特有の注意点

### ① 山間部・茶産地の石材店アクセス問題

静岡県は茶の主産地として知られ、島田市・川根本町・牧之原市・掛川市などの山間・丘陵地帯には古い寺院墓地が多くあります。こうした地域では石材店の数が限られ、以下のような注意点があります。

- 石材店の出張費が都市部より割高になりやすい
- 狭い山道・急勾配の墓地では重機搬入が困難で手作業解体となる場合がある
- 対応可能な石材店を探すのに時間がかかるケースがある

早めに複数の業者へ見積もりを依頼し、作業内容を詳細に確認することが重要です。

### ② 伊豆半島・沼津エリアの別荘・観光地墓地

伊豆半島（伊東市・下田市・松崎町・南伊豆町など）には、かつて別荘地として移住した方のご先祖が眠るお墓や、観光地近くの寺院墓地が点在します。**現在の相続人が関東在住**で遠方管理が続いているケースも多く、改葬を機に地元に戻す相談が増えています。

<InfoBox title="遠方管理のお墓こそ早期相談を">
  静岡県外にお住まいで静岡のお墓を改葬したい場合、行政書士に書類収集・申請代行を依頼することで、現地に何度も出向く手間を大幅に省けます。
</InfoBox>

### ③ 廃寺・無住寺院のお墓

静岡県の中山間地域では、住職不在（無住）や廃寺となった寺院の墓地も散見されます。この場合、**「埋葬証明書」の発行者が不在**となるため、通常の手続きが取れません。現在のお墓がある市区町村の担当窓口に状況を説明し、代替書類や特例的な対応について相談してください。

## 費用相場

静岡県内での改葬・お墓じまいにかかる費用の目安は以下のとおりです。

| 費用項目 | 相場 |
|---------|------|
| 墓石撤去工事費（一般的な規模） | 10万〜25万円 |
| 閉眼供養（魂抜き）のお布施 | 3万〜5万円 |
| 離檀料（任意、法的義務なし） | 0〜10万円 |
| 改葬許可申請書類取得 | 数百円 |
| 行政書士への代行費用 | 5万〜12万円 |
| 遺骨の洗骨・粉骨（必要な場合） | 1万〜3万円/柱 |
| 新しい納骨先（永代供養） | 10万〜50万円 |

**総合計の目安：25万〜90万円**

山間部・離島エリアや、複数柱の遺骨がある場合は上記より高くなる場合があります。石材店・行政書士ともに複数から見積もりを取り、内訳を比較することをおすすめします。

<InfoBox title="離檀料に法的支払い義務はない">
  寺院から離檀料を請求された場合でも、法的な支払い義務はありません。ただし関係をこじらせないよう丁寧に交渉することが重要です。高額請求や強引な対応がある場合は行政書士に相談してください。
</InfoBox>

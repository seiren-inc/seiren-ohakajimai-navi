「長年お参りしてきたお寺が、突然廃寺になってしまった」
「管理事務所に電話しても繋がらず、お墓がどうなるのか不安だ」

こうした状況に直面したとき、何をすればよいのかわからず途方に暮れる方は少なくありません。

お寺が廃寺（廃院・閉院）になった場合のお墓の取り扱いは、通常の墓じまいよりも手続きが複雑になることがあります。しかし、手順を正しく理解すれば、着実に進めることができます。この記事では、廃寺になった場合の**墓じまい・改葬の手続き**を、ステップごとにわかりやすく解説します。

## まず確認すること：廃寺の状況と引受先

廃寺が確認できたら、最初にすべきことがあります。

### 廃寺のパターンを把握する

廃寺にはいくつかの経緯があり、パターンによって引受先や手続きの方法が異なります。

| 廃寺のパターン | 概要 |
|---|---|
| 合併・吸収 | 近隣の寺院に合併・吸収された |
| 無住持化（実質廃業） | 住職が不在となり、寺院としての機能が停止 |
| 宗教法人の解散 | 宗務庁による廃寺処分・法人解散認定を受けた |
| 火災・自然災害による消失 | 建物が失われ、機能が停止した |

最も多いのは「無住持化」と「合併」です。まず菩提寺がどのパターンに当たるかを確認しましょう。

### 引受先・連絡先の探し方

廃寺になった場合でも、墓地の管理権限はいずれかの主体が引き継いでいることがほとんどです。以下の順に確認してください。

1. **墓地の掲示板・看板**：新しい管理者の連絡先が掲示されている場合があります
2. **お寺が属していた宗派の宗務庁**：宗務庁が引受先の情報を把握していることが多い
3. **市区町村の墓地担当窓口**：都道府県知事が許可した墓地台帳で管理者情報を確認できる場合がある
4. **法務局の法人登記**：宗教法人の解散・変更登記から引継先が判明することがある

<InfoBox title="宗務庁への問い合わせが解決への近道になることが多い">
  廃寺になった寺院の宗派がわかれば、その宗派の宗務庁（本山・宗務本庁）に問い合わせることで、引受先や墓地の今後の扱いについて情報が得られることが多いです。宗務庁の連絡先は各宗派の公式サイトで確認できます。なお、宗派不明の場合は墓石に刻まれた家紋や戒名の末尾（「信士」「居士」など）から宗派を推定できることもあります。
</InfoBox>

## 廃寺の場合に必要な書類と取得先

改葬（墓じまい）を行うには、通常の場合と同様に「改葬許可証」が必要です。改葬許可証を取得するには、以下の書類を揃える必要があります。

### 必要書類の一覧

| 書類名 | 通常の場合の取得先 | 廃寺の場合の取得先 |
|---|---|---|
| **埋蔵証明書** | 現在のお寺（住職） | 引受寺院、または市区町村の墓地担当窓口に相談 |
| **改葬許可申請書** | 墓地のある市区町村の役所 | 同左（変わらない） |
| **受入証明書** | 新しい納骨先 | 同左（変わらない） |

### 埋蔵証明書の取得が最大の課題

通常の墓じまいでは、現在のお寺の住職が「埋蔵証明書」を発行します。しかし廃寺の場合は発行者がいないため、代替手段が必要になります。

**対応の流れ（例）：**
1. **引受寺院が存在する場合** → 引受寺院に発行を依頼する
2. **引受先が不明な場合** → 市区町村の墓地担当窓口に「埋蔵証明書に代わる申立書」の扱いを相談する
3. **市区町村が認める場合** → 申請者の申立書と埋葬の事実を証明できる書類（過去の納骨証明書・写真・戸籍謄本など）で代替できるケースがある

手続きの詳細は市区町村ごとに異なるため、**必ず事前に窓口へ確認する**ことが重要です。

<InfoBox title="廃寺の墓地は行政が把握していることも多い">
  都道府県知事の許可を受けた墓地（「許可墓地」）は、行政が台帳で管理しています。お寺が廃寺になった後も、墓地として行政の把握下に置かれているケースがあり、市区町村の窓口で引受先や手続き方法を教えてもらえることがあります。まずは墓地のある自治体の「環境課」「生活衛生課」「市民課」などに問い合わせてみましょう。
</InfoBox>

## 廃寺の墓じまいにかかる費用の目安

廃寺の場合も、墓じまいにかかる費用の大枠は通常の場合と大きく変わりません。ただし、引受先の確認作業や書類収集に手間がかかることがある点に注意が必要です。

| 項目 | 費用目安 |
|---|---|
| 墓石撤去・整地工事 | 20万〜50万円（規模・立地による） |
| 改葬許可申請（証明書発行など） | 数百円〜数千円 |
| 行政書士への依頼（書類収集・交渉含む） | 5万〜15万円 |
| 新しい供養先（永代供養・樹木葬など） | 10万〜100万円 |
| 粉骨・洗骨（必要な場合） | 1万〜5万円 |

廃寺の場合は**離檀料が不要**になることが多いため、その分の費用が抑えられるケースもあります。

## 改葬先の主な選択肢

廃寺の墓じまい後の遺骨の行き先として、以下の選択肢が一般的です。

### 永代供養墓

寺院や霊園が管理者として永続的に供養してくれる形式。後継者不要で、管理の心配が少ない。費用の目安は10万〜100万円程度。

### 納骨堂

屋内施設で天候を問わずお参りできる。都市部に多く、アクセスが良い点が特徴。ロッカー式（20万〜50万円）から自動搬送式（80万〜150万円）まで幅広い選択肢がある。詳しくは「[納骨堂の選び方](/blog/noukotsu-dou-erabikata)」をご覧ください。

### 樹木葬

自然環境の中に埋葬される形式。後継者不要で、合祀型なら5万〜20万円と比較的安価。詳しくは「[樹木葬とは？](/blog/jumokusou-toha)」をご覧ください。

### 海洋散骨

粉骨した遺骨を海に散骨する方法。家族全員の同意が必要。費用は3万〜50万円程度。詳しくは「[海洋散骨ガイド](/blog/kaiyou-sankotsu-guide)」をご覧ください。

## 廃寺の墓じまいでよくあるトラブルと対処法

### トラブル①：引受先が全く見つからない

廃寺後、誰も管理していない「放棄状態」になっているケースがあります。

**対処法：** 墓地のある市区町村の墓地担当課に相談する。行政が墓地の管理権限を持つ法人を特定できる場合があります。それでも解決しない場合は行政書士に相談してください。

### トラブル②：廃寺なのに管理費の請求書が届く

宗務庁や引受法人が管理費の徴収を継続しているケースがあります。

**対処法：** 請求元に「墓じまいをしたい」と申し出る。改葬手続き完了後は管理費の支払い義務がなくなります。支払い済みの管理費については、期間按分で返金されることがあります。

### トラブル③：親族が廃寺の事実を知らず、対応が遅れている

廃寺の情報が親族間で共有されていないと、手続きが進まないことがあります。

**対処法：** 親族に廃寺の事実を伝え、改葬の方針について家族で話し合う機会を設ける。遠方の親族が多い場合は、行政書士に親族調整サポートを依頼することも有効です。

### トラブル④：お墓がいつの間にか撤去されていた

廃寺後に行政代執行や墓地の整理が行われ、墓石が撤去されているケースがまれにあります。

**対処法：** 遺骨の保管状況を市区町村の墓地担当課に確認する。遺骨は適切に保管・合祀されている場合が多く、改葬許可を取得することで取り出せる可能性があります。

## まとめ：廃寺の墓じまいは早めの対応が重要

廃寺になった場合のお墓じまいの全体像をまとめます。

1. **廃寺の経緯と引受先を確認する**（掲示板・宗務庁・市区町村に問い合わせ）
2. **埋蔵証明書の取得先を確認する**（引受寺院または行政窓口に相談）
3. **改葬許可申請書を提出し、改葬許可証を取得する**
4. **墓石撤去工事を行い、遺骨を取り出す**
5. **新しい供養先（永代供養・樹木葬・納骨堂など）に移送する**

廃寺の場合、引受先の特定や埋蔵証明書の取得で通常より時間がかかることがあります。放置すると無縁墓として処理されるリスクもあるため、廃寺を知ったら**早めに動き出す**ことが最善の対処です。

手続きに不安がある方、引受先がわからず困っている方は、専門家への相談をご検討ください。

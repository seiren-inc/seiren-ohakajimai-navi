「海外に移住したが、実家のお墓が日本に残っている」「親族が誰も管理できなくなり、このまま放置できない」──そんな状況で墓じまいを検討している方が年々増えています。

結論として、**海外在住者であっても日本の墓じまい（改葬）を行うことは可能です。** 重要なのは「委任状」の活用と、信頼できる代理人を確保することです。

この記事では、海外在住者特有の課題と、その解決策を具体的に解説します。

## 海外在住者が直面する5つの課題

通常の墓じまいでは、本人が市区町村の窓口に出向いたり、墓地管理者と直接交渉したりする場面が多くあります。海外在住の場合、以下の課題が生じます。

| 課題 | 内容 | 解決策 |
|---|---|---|
| 役所への申請 | 改葬許可申請は代理提出が基本可能 | 委任状＋代理人で対応 |
| 書類への署名・捺印 | 実印・印鑑証明書が必要な書類あり | 在外公館の領事認証で代替 |
| 墓地管理者との交渉 | 離檀・離壇料の交渉を直接できない | 行政書士が代理交渉 |
| 墓石撤去への立ち会い | 工事現場に立ち会えない | 行政書士・代理人が立ち会い |
| 改葬先の契約 | 施設によっては本人確認を求める | 委任状または帰国時に対応 |

これらの課題のほとんどは、**委任状と行政書士の活用**によって解決できます。

## 委任状の作成と在外公館での領事認証

海外在住者が墓じまいを進める際に最も重要な書類が**委任状**です。

委任状には以下の内容を明記します。

- 委任者（本人）の氏名・現住所・連絡先
- 受任者（日本にいる代理人）の氏名・住所
- 委任する業務の具体的な範囲（改葬許可申請、墓地管理者との交渉、施工業者との契約締結、遺骨の引き渡しなど）
- 委任の有効期間

<InfoBox title="在外公館での領事認証について">
委任状に記載した署名が本人のものであることを証明するため、居住国の日本大使館または領事館（在外公館）で**領事認証**を受けることができます。これにより、日本国内での手続きで委任状の真正性が担保されます。在外公館は予約制のことが多いため、早めに問い合わせましょう。認証手数料は1通あたり数千円が目安です。
</InfoBox>

委任状の書式は行政書士に作成を依頼するのが確実です。業務の漏れや不備を防ぎ、役所や墓地管理者に提出できる形式に仕上げてもらえます。

## 代理人・行政書士への依頼

代理人は信頼できる**親族や知人**に依頼することもできます。ただし、役所への書類提出・墓地管理者との交渉・施工業者の手配など、慣れない手続きが集中するため、負担が大きくなりがちです。

**行政書士への依頼が最も安心です。**

行政書士は改葬許可申請などの行政手続きの代理を法律上行える専門家です。次のすべてをワンストップで代行してもらえます。

- 委任状書式の作成・確認
- 市区町村への改葬許可申請
- 墓地管理者（寺院・霊園）との離檀交渉
- 墓石撤去業者の手配・工事への立ち会い
- 改葬先（樹木葬・納骨堂・散骨など）の紹介・手配

行政書士費用の目安は**5万〜20万円**程度です（業務範囲による）。帰国のための往復航空券代・宿泊費と比較しても、費用対効果が高い選択肢となるケースが多いです。

## 手続きの流れと費用の目安

行政書士に依頼した場合の標準的な流れは次のとおりです。

| ステップ | 内容 | 目安期間 |
|---|---|---|
| 1. 相談・委任状の準備 | 行政書士に相談し、委任状書式を受け取る | 1〜2週間 |
| 2. 在外公館での認証 | 委任状に署名し、領事認証を受けて日本へ郵送 | 1〜4週間 |
| 3. 墓地管理者への連絡 | 行政書士が代理で寺院・霊園に連絡・交渉 | 1〜2週間 |
| 4. 改葬許可申請 | 市区町村へ申請。許可証発行まで数日〜2週間 | 1〜2週間 |
| 5. 墓石撤去・遺骨取り出し | 石材店が対応。代理人・行政書士が立ち会い | 1日（予約制） |
| 6. 改葬先への納骨 | 遺骨を新しい埋葬先（樹木葬・納骨堂など）へ | 1〜4週間 |

全体として**2〜4か月**が目安です。

費用の総合目安は以下のとおりです。

| 項目 | 費用目安 |
|---|---|
| 墓石撤去・整地費用 | 10万〜50万円（墓石の大きさによる） |
| 離檀料（寺院墓地の場合） | 0〜30万円（寺院による） |
| 改葬許可申請手数料 | 数百円〜3,000円（市区町村による） |
| 行政書士代行費用 | 5万〜20万円 |
| 改葬先の費用（樹木葬・納骨堂など） | 10万〜80万円 |
| **合計目安** | **30万〜180万円** |

離檀料の相場については[離檀料の相場と交渉のポイント](/column/ridanryou-soba)も参考にしてください。

## 改葬先の選び方

墓じまい後の遺骨の受け入れ先として、海外在住者には次の選択肢が人気です。

**樹木葬・永代供養墓（合祀型）**: 後継者・管理者が不要で費用が比較的安価です。帰国頻度が低い方に向いています。

**納骨堂**: 都市部のアクセスしやすい場所に多く、帰国の際にお参りしやすい立地を選べます。

**海洋散骨**: 管理が不要で、一度きりの供養として完結します。遺骨を粉砕（粉骨）して散骨します。

<InfoBox title="海外在住者がよく見落とすポイント">
遺骨の海外への持ち出しを検討する場合は、渡航先の国の規制・検疫・通関ルールを事前に確認する必要があります。日本国内での改葬（国内の別施設へ移す）であれば、この問題は発生しません。不明な点は行政書士または渡航先の在日大使館に相談してください。
</InfoBox>

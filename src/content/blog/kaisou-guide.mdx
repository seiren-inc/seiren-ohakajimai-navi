「お墓を別の場所に移したいけど、何から始めればいい？」「改葬と墓じまいは何が違うの？」

改葬（お墓の引越し）は、法律上の手続きを伴う作業です。この記事では、改葬の意味から費用・手続き・清蓮に相談できることまで、全体像をわかりやすくまとめました。

## この記事の結論

- **改葬**とは、遺骨を現在の墓地から別の場所に移すことを指す法律上の手続きです。必ず改葬許可証の取得が必要です。
- **費用**は、墓石撤去・離檀料・新しい納骨先の費用を合わせると総額50万〜150万円程度が目安ですが、状況により大きく異なります。
- **清蓮**では、墓石撤去、遺骨の取り出し、粉骨・洗骨、散骨、次の供養先選びまで相談できます。
- 改葬許可申請書の書類作成代行が必要な場合は、提携行政書士のご紹介も行っています。

---

## 改葬とは何か

**改葬（かいそう）**とは、法律上「埋葬または収蔵した死体（骨・灰を含む）を他の墓地や納骨堂に移すこと」をいいます（墓地埋葬法 第2条）。

わかりやすく言うと「お墓の引越し」です。

<InfoBox title="なぜ許可が必要なの？">
日本では「墓地、埋葬等に関する法律（墓埋法）」により、改葬許可証なしに遺骨を移動させることは違法です（同法 第5条）。現在の墓地から遺骨を取り出す前に、必ず市区町村の窓口で改葬許可証を取得しなければなりません。
</InfoBox>

### 改葬と墓じまいの違い

混同されがちですが、厳密には異なる概念です。

| 用語 | 意味 |
|---|---|
| **改葬** | 遺骨を別の場所へ移す「法的手続き」 |
| **墓じまい** | お墓の墓石を撤去・解体して更地に戻す「物理的な作業」 |
| **お墓じまい** | 墓じまい＋改葬を含む一連のプロセス全体を指すことが多い |

多くの場合、お墓じまいをして遺骨を別の供養先へ移す場合には、改葬と墓じまいの両方が必要になります。詳しくは[改葬と墓じまいの違い](/column/kaisou-vs-hakajimai)をご覧ください。

## 改葬が必要になる主なケース

- **お墓じまい**をして遺骨を永代供養墓・樹木葬・納骨堂などへ移す
- **遠方のお墓**を自宅近くに引っ越したい
- **宗教・宗派の変更**に伴いお寺から霊園へ移す
- **無縁墓にならないよう**管理できる別の場所へ移す
- **海洋散骨・樹木葬・手元供養**など新しい供養の形を選ぶ

遠方のお墓が管理できない方向けの対処法は[こちらの記事](/column/enpo-ohaka-kanri)でも詳しく解説しています。

## 改葬の手続きと必要書類

改葬許可申請を完了させるまでの流れは、大きく**4つのステップ**に分かれます。

### ステップ1：改葬先（新しい供養先）を決める

まず「次にどこへ遺骨を移すか」を決めます。新しい納骨先が決まったら、管理者から**受入証明書**を発行してもらいます。

改葬後の供養先の選択肢は[こちらのページ](/kaisougo)で比較できます。

### ステップ2：現在のお墓から埋葬証明書をもらう

現在ご遺骨が納められている墓地・お寺の管理者（住職・霊園管理事務所）から**埋葬証明書（納骨証明書）**を発行してもらいます。

### ステップ3：改葬許可申請書を提出する

現在のお墓がある市区町村の窓口に、以下の書類をまとめて提出します。

1. **改葬許可申請書**：市区町村窓口またはWEBでダウンロード
2. **埋葬証明書**：現在の墓地管理者から取得
3. **受入証明書**：新しい供養先から取得

全国1,700以上の市区町村の申請書は[改葬許可申請書ダウンロードページ](/kaisoukyoka)からご確認いただけます。

<InfoBox title="改葬許可申請の代行について">
改葬許可申請書の作成・代理提出は、行政書士など有資格者のみが行える業務です。清蓮では申請書のダウンロード先案内・一般的な記入説明・提携行政書士のご紹介を行います（代行は行いません）。書類作成に不安がある場合は行政書士への相談も選択肢です。
</InfoBox>

### ステップ4：改葬許可証を受け取り、遺骨を移動する

改葬許可証が発行されたら、現在の墓地から遺骨を取り出し、新しい供養先へ移します。

墓石撤去工事は、改葬許可証の取得後に行うのが基本です。[お墓じまいの流れ全7ステップ](/flow)も参考にしてください。

## 改葬にかかる費用の相場

改葬にかかる費用は、内容によって大きく異なります。以下は一般的な目安です。

| 費用項目 | 目安 |
|---|---|
| 改葬許可申請 | 無料（自治体手数料が発生する場合あり） |
| 墓石撤去・解体工事 | 10万〜50万円程度 |
| 離檀料（お布施） | 3万〜20万円程度（法的義務なし） |
| 閉眼法要（魂抜き） | 3万〜5万円程度 |
| 粉骨・洗骨 | 1万〜5万円程度 |
| 新しい納骨先の費用 | 10万〜150万円程度（種類により大きく異なる） |
| 行政書士への依頼費用 | 3万〜15万円程度（依頼した場合） |

追加費用が発生しやすいケース、費用を安く抑えるコツは[お墓じまいの費用相場](/column/cost-of-hakajimai)をご参照ください。

## 改葬先の選択肢と特徴

改葬後の遺骨をどこへ移すかは、費用・管理のしやすさ・宗教観などを考慮して選びます。

| 供養先 | 費用目安 | 特徴 |
|---|---|---|
| 永代供養墓（合同墓） | 5万〜30万円 | 合祀されるため将来の管理不要 |
| 樹木葬 | 10万〜80万円 | 自然の中で眠れる。人気が高い |
| 納骨堂 | 10万〜100万円 | 屋内管理でアクセス良好 |
| 海洋散骨 | 3万〜20万円 | 自然に還る。墓地不要 |
| 手元供養 | 数千円〜 | 自宅で遺骨を保管。改葬届不要の場合も |

各供養先の詳しい費用・メリット・デメリットは[改葬後の供養先比較ページ](/kaisougo)でご確認いただけます。

## 清蓮に改葬・お墓じまいで相談できること

清蓮（株式会社清蓮）は横浜を拠点に、お墓じまいの工事から供養先の手配まで全国対応しています。

| 対応内容 | 清蓮でできること |
|---|---|
| 相談・流れの整理 | ご状況に合わせてお墓じまいの全体像を整理 |
| 墓石撤去工事 | 提携石材店による撤去・原状回復（全国対応） |
| 遺骨の取り出し | 丁寧な取り出しと状態確認 |
| 粉骨・洗骨 | 自社サービスとして対応 |
| 海洋散骨 | 散骨クルーズと連携して対応 |
| 供養先の案内 | 永代供養・樹木葬・納骨堂など状況に応じてご紹介 |
| 行政書士紹介 | 改葬許可申請の書類作成が必要な場合にご紹介 |
| 費用見積もり | 現地調査後に確定見積もり（無料） |

改葬許可申請書の作成代行は行政書士業務のため清蓮では行いませんが、提携行政書士のご紹介は可能です。

## 改葬で注意すべきポイント

### 自治体によって手続きが異なる

改葬許可申請書の書式・必要書類の種類・提出先の窓口名は、自治体によって異なります。事前に現在のお墓がある市区町村へ確認することをおすすめします。

### 離檀料に法的な支払い義務はない

お寺からの離檀を求める際に「離檀料」を請求されることがあります。ただし、離檀料に法的な支払い義務はなく、一般的なお布施の相場（3万〜10万円程度）を包むケースが多いです。高額な請求があった場合は、専門家への相談を検討してください。詳しくは[離檀料の相場と対処法](/ridanryou)をご覧ください。

### 散骨は改葬許可が不要な場合もある

自宅に保管している遺骨を散骨する場合など、状況によっては改葬許可申請が不要なケースがあります。個別の事情により異なるため、事前に確認してください。

## よくある質問

**Q. 改葬先が決まっていない段階でも相談できますか？**
はい、改葬先が決まっていない段階でも相談いただけます。永代供養・樹木葬・海洋散骨など、ご状況に合わせた選択肢をご案内します。

**Q. お墓が複数ある場合、一括で相談できますか？**
はい、対応可能です。複数のお墓をまとめてお墓じまいされるケースにも対応しています。

**Q. 改葬許可申請の書類を間違えて差し戻しされた場合はどうなりますか？**
差し戻し後に再提出が必要になります。よくある記入ミスや差し戻し防止のポイントは、[改葬許可申請書の書き方ガイド](/column/kaisoukyokashinseisho-kakikata)でご確認いただけます。

**Q. 工事中の写真記録はもらえますか？**
清蓮では墓石撤去工事の写真記録を提供しています。遠方でご立会いが難しい方にも対応しています。

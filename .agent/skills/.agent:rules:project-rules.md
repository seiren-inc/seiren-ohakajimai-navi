# Project Rules\
\
## Non-Negotiable Rules\
\
- Preserve existing routes unless explicitly instructed\
- Preserve existing SEO metadata unless the task is SEO-related\
- Preserve existing municipality data unless the task is data-related\
- Do not perform unrelated refactors\
- Do not rename files, routes, components, or data fields without approval\
- Do not introduce large dependencies without approval\
- Do not change public wording in legally sensitive areas without review\
\
## Sensitive Areas\
\
Treat these areas as high-risk:\
\
- Municipality data\
- Reburial permit information\
- Administrative scrivener listings\
- Contact forms\
- SEO routes\
- Sitemap\
- Structured data\
- Database schema\
- Public legal/process explanations\
\
## Required Reporting\
\
Every implementation report must include:\
\
- Changed files\
- What changed\
- What did not change\
- Validation commands\
- Validation results\
- Remaining risks}
